# SEO, GEO and AEO

Canonical origin: `https://facupresa.com` (set once, in [`src/seo/site.ts`](../src/seo/site.ts)).

The site is a client-rendered SPA. Social scrapers and most AI crawlers do not
run JavaScript, so everything below exists to put real content and metadata in
the HTML they download.

---

## What ships

| Piece | Where | What it does |
| --- | --- | --- |
| Head tags | `index.html` placeholder, filled by `vite-plugins/seo.ts` | Title, description, canonical, robots, theme-color, Open Graph, Twitter card |
| Structured data | same | JSON-LD `@graph`: `WebSite` + `Person` on every page, plus `Blog` / `BlogPosting` / `BreadcrumbList` on blog routes |
| Static fallback | `<div id="root">` in the built HTML | English copy of the page (h1, summary, background, orgs, projects, contact). React replaces it on mount |
| Prerendered routes | `dist/blog/index.html`, `dist/blog/<slug>/index.html` | Own title, canonical, OG tags, JSON-LD and article body per post |
| Client-side head | [`src/seo/useHead.ts`](../src/seo/useHead.ts) | Keeps the head correct when navigating inside the SPA; restores the previous values on unmount; `noindex` on a missing post |
| `sitemap.xml` | generated | `/`, `/blog/`, every post with `lastmod` from frontmatter `date` |
| `llms-full.txt` | generated | Whole portfolio (bio, orgs, every project with story and milestones, every post) as one plain-text file |
| `llms.txt` | `public/llms.txt`, hand-written | Short summary and link list (llmstxt.org) |
| `robots.txt` | `public/robots.txt` | Allows everything; names the AI search and training crawlers explicitly |
| Social card | `public/og.png` (1200×630) | Generated by [`scripts/generate-og.py`](../scripts/generate-og.py) |
| Icons | `public/favicon-48.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `site.webmanifest` | Resized from `logo.png` by the same script |

## Decisions

- **Trailing slash is canonical** for prerendered routes (`/blog/`, `/blog/<slug>/`). They are
  emitted as `<route>/index.html`, which a static server reaches through a trailing-slash
  redirect; pointing the canonical at the final URL avoids a canonical that itself redirects.
- **One URL per page, two languages.** The locale is chosen client-side (browser language, then
  the reader's toggle), so there are no per-language URLs and therefore no `hreflang`. The static
  HTML is English. If Spanish should rank on its own, it needs real URLs (`/es/…`).
- **AI crawlers: all allowed**, training bots included (`GPTBot`, `ClaudeBot`, `Google-Extended`,
  `Applebot-Extended`, `CCBot`). This is a portfolio; being quoted is the point. To opt out of
  training only, change those groups in `robots.txt` to `Disallow: /`.
- **The static fallback is not hidden.** It is real content with the same text as the page, painted
  by the stylesheet until React mounts. No `display:none`, no off-screen positioning.
- **Description opens with a definition** ("Facundo Presa is an entrepreneur, designer and developer
  from Uruguay…") so snippets and answer engines get a self-contained sentence.

## Adding content

- **A blog post**: drop a `.md` in `posts/` with `title`, `date`, `author`, `tags`; optional
  `description`, `seoTitle`, `seoDescription`, `cover`. Sitemap, prerender, JSON-LD and
  `llms-full.txt` pick it up on the next build. A post's leading `# Title` line is dropped from the
  prerendered body because the page already has an `<h1>` with the title.
- **A project**: edit `src/config.ts`. The static fallback and `llms-full.txt` read it directly.
- **A new social card**: edit `scripts/generate-og.py`, run `python -I scripts/generate-og.py`
  (needs Pillow; uses Arial Bold from `C:\Windows\Fonts` in place of Inter).

## Verify after deploy

```bash
curl -s https://facupresa.com/ | grep -E '<title>|canonical|og:image|ld\+json'
curl -s https://facupresa.com/blog/example-post/ | grep -E '<title>|canonical'
curl -sI https://facupresa.com/og.png | grep -i -E 'HTTP|content-type'
curl -s https://facupresa.com/sitemap.xml | head
```

Then paste the home and a post URL into the LinkedIn Post Inspector, the Facebook Sharing Debugger
and Google's Rich Results Test, and submit `sitemap.xml` in Search Console.
